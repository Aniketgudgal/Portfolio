# Aniket Gudgal | Portfolio

A clean, responsive portfolio website for Aniket Gudgal, highlighting experience as a Java Full Stack Developer, projects, technical skills, education, and contact information.

## Live Preview

Preview the site locally by opening `index.html` in a browser, or serve the project folder with a local web server.

## Project Structure

- `index.html` — portfolio structure and content
- `styles.css` — layout, design, and responsive styling

The profile photo and downloadable resume are maintained on the `gh-pages` branch for the deployed portfolio.

For a local preview that includes the profile image and downloadable resume, use the `gh-pages` branch.

## Run Locally

### Option 1: Open directly

- Double-click `index.html` in the project folder.

### Option 2: Use a local server

From the project folder, run:

```bash
python -m http.server 8000
```

Then open the site in your browser at:

```text
http://localhost:8000
```

## GitHub Pages Deployment

Configure GitHub Pages to deploy from the `gh-pages` branch so that the profile image and resume remain available on the live site.

To configure GitHub Pages:

1. Open the repository on GitHub.
2. Go to `Settings` → `Pages`.
3. Under `Build and deployment`, select `Deploy from a branch`.
4. Choose the `gh-pages` branch and the `/ (root)` folder.
5. Save the settings.
6. GitHub Pages will publish the site at:

```text
https://aniketgudgal.github.io/Portfolio/
```

Changes to the live portfolio should be pushed to `gh-pages`.
